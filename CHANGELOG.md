### Added

- Timeline above every chat: messages per month (per day for short chats), click, drag or arrow keys to jump,
  search hits as dots.
- Hidden chats (as in WhatsApp) when the decrypted `msgstore.db` lies in the export folder.
- README guide from the phone to the archive, logo, and screenshots from a scripted showcase archive
  (`DemoArchive --showcase`, `npm run screenshots`).
- Contact names and profile pictures from an address-book export (`--contacts file.vcf --country-code 49`).
- Initial chat list, chat view, media viewer and full-text search for WhatsApp-Chat-Exporter JSON exports.
