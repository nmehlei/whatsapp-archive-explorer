# Security policy

This tool handles very private data. Please report vulnerabilities **privately** via
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository — not in a public issue.

In scope, for example: reading chats or media from another website or another user, path traversal out of
the archive, script injection through message content, writes into the archive, data leaving the machine.

Only the latest release is supported.
